## 4. Hub & Spokes — Internal Linking Blueprint

### 4.1 Link Flow Rules
- **Hubs → Spokes:** Every pillar links to ALL its spokes
- **Spokes → Hub:** Every spoke links back to its pillar
- **Outer → Core:** Discovery content (clusters 4-5) links inward to recipes (clusters 1-3)
- **Cross-cluster:** Spokes sharing the same entity link to each other
- **No orphans:** Every page must be reachable via internal links
- **No excessive outward linking:** Core pages should NOT link extensively to Outer pages
