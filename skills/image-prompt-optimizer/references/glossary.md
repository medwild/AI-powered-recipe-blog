# Glossaire professionnel — Photo / Éclairage / Composition / Art

Glossaire de référence rapide. Pour chaque terme : définition courte + fiabilité du terme en prompt IA (Très élevée/Élevée = à utiliser sans hésiter ; Modérée = utile mais moins déterminant ; Faible/N/A = préférer décrire l'effet plutôt que le terme technique de capture).

## Termes photographiques

| Terme | Définition | Applicabilité IA |
|---|---|---|
| Aperture (ouverture) | f/X.X — plus le nombre est petit, plus l'ouverture est grande | Élevée — "f/1.4", "f/2.8", "f/8" produisent des DoF cohérentes |
| Bokeh | Qualité esthétique du flou hors-focus | Élevée — "creamy bokeh" très fiable |
| Bracketing | Prises multi-expositions pour HDR | Faible — technique de capture, pas de génération |
| Chromatic aberration | Franges de couleur aux hauts contrastes | Modérée — "subtle chromatic aberration" ajoute du réalisme |
| Color grading | Correction chromatique en post-production | Élevée — "teal and orange color grade" très efficace |
| Color temperature | Température en Kelvin (K) de la lumière | Très élevée — "3200K warm" ou "5600K daylight" précis |
| Crop factor | Conversion entre capteurs | Faible — préférer la focale équivalente full-frame directement |
| Dynamic range | Plage de luminosité capturable | Modérée — "high dynamic range" |
| Exposure compensation | Ajustement par rapport au mesurage auto | Faible — préférer "slightly underexposed"/"properly exposed" |
| Focal length | Distance focale en mm | Très élevée — "85mm", "24mm" parmi les termes les plus fiables |
| F-stop | Voir Aperture | Très élevée |
| Grain | Texture granuleuse argentique | Élevée — "film grain" donne un rendu organique |
| ISO | Sensibilité du capteur | Modérée — "low ISO clean image" / "high ISO grainy" |
| Shutter speed | Vitesse d'obturation | Modérée — "motion blur from slow shutter" efficace |
| Vignetting | Assombrissement des bords | Élevée — "natural vignetting" bien reconnu |
| White balance | Compensation dominante de couleur | Élevée — "tungsten white balance", "daylight balanced" |

## Termes de composition et d'art

| Terme | Définition | Applicabilité IA |
|---|---|---|
| Chiaroscuro | Traitement violent des clairs-obscurs (Renaissance/Baroque) | Élevée — produit un contraste dramatique |
| Focal point | Point d'attention principal | Élevée — "strong focal point on..." |
| Golden ratio | Proportion 1:1.618 | Modérée — moins fiable que la rule of thirds en IA |
| Gouache | Peinture à l'eau opaque | Élevée — "gouache painting style" |
| Impasto | Peinture épaisse, empreintes de pinceau | Élevée — "impasto texture", "thick oil paint strokes" |
| Perspective | Représentation de la profondeur sur surface plane | Élevée — "one-point perspective", "aerial perspective" |
| Sfumato | Transition douce entre couleurs (Léonard de Vinci) | Élevée — pour des transitions atmosphériques |
| Trompe-l'œil | Illusion d'optique faisant croire au réel | Élevée — "trompe-l'oeil style" |
| Vanishing point | Point de fuite en perspective | Élevée — "converging lines to a single vanishing point" |
